What is the Command Line Interface (CLI)?

The CLI is a powerful interface that allows you to interact with your system through text commands. It's fast, efficient, and gives you control over your machine.

Basic Commands to Practice

  • cd – Change directory. E.g., cd Documents to enter the Documents folder.
  • dir – List files and directories in the current directory.
  • mkdir – Create a new directory. E.g., mkdir new_folder to create a folder.
  • echo – Display a message. E.g., echo Hello, World!
  • cls – Clear the screen (useful for a clean slate).
  • copy – Copy files from one location to another. E.g., copy file1.txt file2.txt
  • del – Delete a file. E.g., del file1.txt
  • type – Display the contents of a text file. E.g., type file1.txt

Advanced Commands

  • sfc /scannow – Scans and repairs corrupted system files.
  • systeminfo – Gives a detailed system summary.
  • chkdsk – Checks disk for errors.
  • net user – Lists users on the system.
  • net user <username> – Displays details about a specific user.
  • tree /f – Graphically displays folder and files structure.
  • rmdir – Removes a folder.
  • where <filename> – Finds the full path of a file that exists in directories listed in the PATH variable.
  • ren <oldfilename.ext> <newfilename.ext> – Renames a file.

How to Open Command Prompt in Windows

  • Search for "cmd" in the Start Menu and press Enter.
  • Press Win + R, type cmd, and press Enter.
  • Right-click Command Prompt and choose "Run as Administrator" to open with admin privileges.
